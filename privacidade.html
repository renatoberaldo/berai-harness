Política de privacidade

BerAI Harness · atualizada em 20/10/2026

O BerAI Harness é um sistema de uso pessoal e privado de Renato Beraldo, que roda no computador dele. Esta política explica o que ele faz com os dados do Google.

Que dados do Google o app acessa

  • Eventos do Google Agenda da conta que autorizou: título, data e hora, local e descrição — para mostrá-los na agenda do app e para criar, alterar ou remover eventos quando o dono pede.
  • A lista de agendas da conta (nome e cor), só para leitura — para separar agendas como Pessoal e Trabalho.

O app não acessa e-mail, contatos, arquivos nem outros dados da conta.

Onde os dados ficam

Os eventos são guardados apenas no computador do dono, no banco de dados local do app. A credencial de acesso fica num cofre de senhas do próprio dono. Nada é enviado a servidores do desenvolvedor, porque não existem servidores do desenvolvedor.

Compartilhamento

Os dados do Google não são vendidos nem usados para publicidade. A única transferência é esta: quando o dono pergunta algo sobre a agenda a um assistente do app, o texto dos eventos relevantes vai ao provedor de IA que gera a resposta (por exemplo, a Anthropic), só para produzir essa resposta ao próprio dono. O app não usa os dados para treinar modelos de inteligência artificial. O uso segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

A qualquer momento, em myaccount.google.com/permissions, remova o acesso do "BerAI Harness". A partir daí o app deixa de ler e de alterar a agenda.

English summary

BerAI Harness is a private, single-user assistant that runs on its owner's own computer. It accesses only the authorized account's Google Calendar events and calendar list, to display and manage the owner's own calendar. Data is stored locally on the owner's machine and is never sold or used for advertising. When the owner asks an assistant about the calendar, the relevant event text is sent to the AI provider that generates the answer (e.g. Anthropic), solely to produce that answer for the owner. The app does not use the data to train AI models. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
